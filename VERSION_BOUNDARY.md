# Evidence Version Boundary

- **V15.5 is the primary evidence release** for the manuscript. Use the V15.5 release metadata, V15.5 task matrices, preserved V15.5 per-seed outputs, and V15.5 analysis exports for reported values.
- Some V15.4-named files are retained solely as provenance or historical source inputs required by the V15.5 analyses. They are not pooled as V15.5 result observations.
- **V16 is not included and no V16 result is used.** Do not combine later-version results with this package without a separately documented, author-approved analysis.
- This package validates analysis from preserved outputs. It does not claim an exact rerun of all historical training.
