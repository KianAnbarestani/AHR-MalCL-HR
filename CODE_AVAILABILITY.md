# Code availability

This repository contains the V15.5 analysis and validation code, protocol configurations, preserved result artifacts, task matrices, figures, and the verified Standard-A runner source described in README.md.

The package supports deterministic analysis reproduction from the included evidence. It does not claim complete reproduction of every historical training run. The adapted-MalCL per-task matrix provenance is preserved-output-only, and a K-sensitivity training runner is not included.

The corresponding manuscript should cite the verified GitHub repository URL after that destination is available. Keep the repository citation and manuscript availability statement synchronized with the actual remote.
