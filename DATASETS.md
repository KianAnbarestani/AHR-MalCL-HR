# Datasets

The experiments use four prepared NPZ artifacts from MalCL's Zenodo record (DOI 10.5281/zenodo.14537891):

- EMBER_Class_train.npz
- EMBER_Class_test.npz
- AZ_Class_Train.npz
- AZ_Class_Test.npz

The arrays are excluded from this repository. Download and verify them using scripts/download_and_verify_datasets.py. The script checks the published MD5 values and expected shapes and labels. Follow the source Zenodo record for attribution and license terms.
