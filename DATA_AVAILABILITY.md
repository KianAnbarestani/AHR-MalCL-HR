# Data availability

This repository does not redistribute the four prepared dataset arrays, raw APKs, or credentials. The arrays used by the experiments are available from the source MalCL Zenodo record, DOI 10.5281/zenodo.14537891. Consult the record for the rights and attribution terms that apply to each file.

The repository license does not replace or extend the source-record terms. Download and validate the arrays with:

    python scripts/download_and_verify_datasets.py --data-dir data --sha256
